# Relational Data Analysis | SQL

This interview-portfolio project combines 11 SQL queries from coursework using flight and digital-media relational databases.

## Skills demonstrated
- Common table expressions (CTEs)
- Multi-table JOINs and self-joins
- Subqueries
- GROUP BY and HAVING
- Conditional aggregation with CASE WHEN
- DISTINCT, filtering, ordering, and NULL handling
- Set operations with EXCEPT
- Relationship and exception analysis across relational tables

## How to read the SQL file
Each query now includes:
1. A concise query title
2. The analytical purpose / question
3. A short explanation of the approach
4. The original SQL query, preserved without changing its logic

The comments are intended to show both SQL ability and the reasoning behind each analytical task.
